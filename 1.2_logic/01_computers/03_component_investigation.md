# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU |To process all data and execute program instructions. |Model & Speed: Brand( Intel/AMD),series(e.g, Corei5, Ryzen7),and clock speed in GHz. |
| RAM |To hold the data temporarily which active programs need to access immediately. | |
| Storage |Permanent long term memory where operating system, files, apps and games are saved. | |
| Motherboard | It connects all internal components and lets them communicate. | |
| Power Supply |To convert high voltage AC electricity from wall outlet into usable DC power for internal parts | |
| Cooling | To dissipates heat generated by the CPU and other parts using fans or metal heatstinks to avoid crashing. | |
