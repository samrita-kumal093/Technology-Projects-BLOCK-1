# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
Hardware refers to the physical parts of a computer that we can see and touch. It includes devices such as the keyboard, mouse, monitor, printer, motherboard, hard drive, and CPU. Hardware is important because it helps a computer perform different tasks. For example, the keyboard is used to type information, the mouse helps us select items, and the monitor displays information on the screen. Hardware works together with software to make a computer function properly.

## Explain Software
Write **at least 50 words** explaining what software is.
Software is a set of programs and instructions that tells a  computer what to do. Unlike hardware, software cannot be touched because it is not a physical part of the computer. It helps users perform different tasks, such as typing documents, playing games, browsing the internet, and drawing pictures. Examples of software include Microsoft Word, Google Chrome, Paint, and computer operating systems like Windows. Software works together with hardware to make a computer function properly.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Hardware and software work together to make a computer function properly. Hardware refers to the physical parts of a computer, while software consists of programs and instructions that tell the computer what to do. Software sends instructions to the hardware, and the hardware carries out those instructions. For example, when we type on a keyboard, the computer processes the information and displays the words on the monitor. Without hardware, software, cannot run, without software, hardware  cannot perform most useful tasks.
