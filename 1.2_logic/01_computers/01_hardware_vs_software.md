# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.

Hardware refers to the tangible, physical parts of a computer system or electronic device that you can see and touch.It consist of all the electronic and mechanical devices that work together to make a computer function properly.

## Explain Software
Write **at least 50 words** explaining what software is.

Software is a set of programs, instruction and data that tells a computer what to do and how to perform different tasks. Unlike hardwrae, software cannot be physically touch. 

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.

Software and Hardware interact through a continuous loop of communication where the software acts as the thinker and the hardware acts as the doer. When users use a computer, software translates users commands into electrical signals. It then passes the signals down the physical hardware which execute the actual work and sends the results back up to the software after completion of the work. And the result is displayed on the user's screen.
